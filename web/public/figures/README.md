# Driver / hero artwork (right flank)

One image per GP, named after its data slug:

    silverstone-2026.jpg

Works best when the artwork is LIT ON BLACK (like a wallpaper render): the
hero blends it with `screen`, so the black disappears into the night and only
the driver and the glow remain. No cut-out needed.

A transparent PNG also works. Portrait or square crops sit best.
