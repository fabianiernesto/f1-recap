# Landmark photos

One cut-out PNG per GP, named after its data slug:

    silverstone-2026.png   ->  Big Ben
    monza-2026.png         ->  Duomo
    spa-2026.png           ->  Atomium

Requirements:
- PNG with a TRANSPARENT background (the sky is ours, not the photo's)
- portrait crop, at least 1200 px tall
- a licence that allows commercial use (Unsplash, Pexels, Wikimedia PD/CC0,
  or a photo Ernesto owns). Never a watermarked stock preview.

Drop the file in and the hero picks it up automatically; with no file it
falls back to the line-art drawing.
